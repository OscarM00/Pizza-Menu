# Pizza-Menu

I built this project using HTML, CSS, and JavaScript.
You can choose a pizza crust, sauce, and toppings,
It shows your order and the total price.

## Versions

This project has two versions in which you can switch between the two in the upper left hand corner.
- index.html: Type in your pizza choices.
- improved.html: Choose from dropdowns and checkboxes.

I kept both versions to show the changes I made.
You can switch between them using the links on each page.

## Pricing

The pizza starts at $5.50, with crust and sauce included.
Each topping costs $2.50 extra.

## Updates

- Fixed the topping prices and total.

- Made empty topping fields count as no topping.
- Added dropdowns and checkboxes in the second version.
- Added links between pages and a hover effect.

## How to use it

Open index.html or improved.html in your browser,
choose your pizza options, and click Create Order.

This is a practice project. It calculates prices but
doesn't save or send real orders.
